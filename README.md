# Tech Job Market Intelligence Dashboard
An AI -powered streamlit web application that analyzes technology job market trends.
##Features
-job market analytics
-skill demand visualization
-salary prediction using machine learning
-city comparision dashboard
-AI-generated market insights
## Tech Stack
Python,pandas,dtreamlit,plotly,scikit-learn
##Purpose
Helps Students and job seekers understand:
-Most demanded skills 
-salary trends
-location-wise opportunities
